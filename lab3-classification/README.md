# Lab 3 Customer risk classification

Explores a 200-row teaching dataset and compares logistic regression with random forest. Includes stratified splitting, fold-specific scaling for cross-validation, confusion matrices and macro-averaged metrics. Supplied risk labels and small-sample scores should not be treated as validated real-world churn outcomes.

Open `group26_lab3.ipynb` with the notebook directory as the working directory. Install the repository's requirements first. The course-provided input files remain beside the notebook in the paths it expects.

Original Group 26 academic attribution is preserved in the notebook. See the root `PUBLICATION_NOTES.md` for changes made for publication and `DATA_SOURCES.md` for provenance.
