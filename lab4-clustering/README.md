# Lab 4 EV charging exploration

Uses scaling, PCA, K-means, silhouette analysis and visualisation to explore an EV charging teaching dataset. The resulting groups support an exploratory classroom analysis, not a verified expansion recommendation.

Open `Group26_Lab4.ipynb` with the notebook directory as the working directory. Install the repository's requirements first. The course-provided input files remain beside the notebook in the paths it expects.

Original Group 26 academic attribution is preserved in the notebook. See the root `PUBLICATION_NOTES.md` for changes made for publication and `DATA_SOURCES.md` for provenance.
