## Currently available

### Lab 1: Python Data Handling

The `lab1-python-data-handling` directory contains:

- A Jupyter notebook exploring NBA data.
- The accompanying CSV dataset.
- The laboratory brief.

The notebook covers data inspection, filtering, grouping, descriptive analysis and visualisation using Python.

## Running the notebook

You will need Python, Jupyter Notebook or JupyterLab, and these packages:

```bash
python -m pip install pandas numpy matplotlib notebook
```

Open a terminal in the `lab1-python-data-handling` directory and start Jupyter:

```bash
python -m notebook
```

Open `lab1_groupno26.ipynb` and run the cells in order. Keep `nba_all_elo.csv` in the same directory as the notebook.

These are the packages used by the uploaded notebook. A pinned, independently verified environment has not yet been added.
