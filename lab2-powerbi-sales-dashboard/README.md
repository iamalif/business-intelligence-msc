# Lab 2 Power BI supporting data

Supporting datasets for the Business Intelligence course's startup-expansion exercise.

- `StartupExpansion.xlsx`: supplied startup-expansion workbook.
- `US-Cities-Population.csv`: supplied city population data.

The completed Power BI `.pbix` file and dashboard screenshots were not located in the source collection when preparing this upload. This folder therefore provides supporting data only, not a published dashboard. No dashboard results or screenshots are claimed here. The private step-by-step working guide has not been published as if it were a finished analysis.

These are course-provided materials, not datasets authored by the repository owner. No new licence or ownership claim is applied to them.
